# Malak Birthday Website 💖

A responsive, romantic birthday website made with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. For best results, use VS Code + the Live Server extension.
3. Unlock with `28 / 01 / 2026`.

## Add your media
- Replace `assets/images/image_0.png` with the shoes/denim photo.
- Replace `assets/images/image_1.png` with the night hand-holding photo.
- Add a song named `our-song.mp3` to `assets/audio/` (or use **+ Add song** in the site).
- Use the **Add Photo** and **Add Video** controls to preview media from your device during the current session.

## Customize
- Birthday password: in `script.js`, find `entered === '28/01/2026'`.
- Edit the Arabic/English birthday message in `index.html`.
- Change colors, layout, and animations in `style.css`.

## Notes
- The project does not include private photos, video, or a copyrighted song; add your own files.
- Add Photo / Add Video previews selected files locally in the current browser session; they do not upload anything to a server.
- The page uses Google Fonts when internet is available and falls back to system fonts offline.
